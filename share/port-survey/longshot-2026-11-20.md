### 3. FreeAddressRegion gives its virtual core up while the pages are discarded (702a57a4, #1646) - PORT FIRST, gate
- What: freeing a large address region hands its pages back to the OS for milliseconds while the freeing thread (the
  game's resource memory thread) kept its virtual core. Now the region is marked "freeing" (stays listed so nothing is
  handed out over it), the core is given up for `discard_pages`, then the region is unlisted.
- Measured: on current Longshot main, Market 3 runs a side: frames the same, waits for a core >= 50 ms 287 -> 19. **On an
  older main (c507b98c) waits >= 300 ms gone and the 1% low 29 -> 35 fps.** Ours lacks #1339 (the import check that
  takes a core back), so ours is closer to that older main. Caveat: our 11-18 HOS_VCORE_STARVE_US A/B removed every core
  wait over 50 ms without moving the Market's 1% low, so the gain may be small here.
- Ours: **missing** (host/hos_mem.c `hos_region_free` keeps the core). Size ~40 lines + test. No randomizer file. Risk
  low (one more give-up per region freed; a double free is handled). Market gate.
